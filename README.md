# AI-Powered Virtual Assistant

A simple AI-powered virtual assistant called **Jarvis**, built using Python and an AI API.

## Features

* Accepts questions and commands from the user
* Generates AI-based responses
* Maintains conversation history during the session
* Runs continuously until the user types `exit`

## Technologies Used

* Python
* OpenAI Python SDK
* Gemini API

## How to Run

1. Install the required Python package:

```bash
pip install openai
```

2. Add your Gemini API key securely as an environment variable.

3. Run the Python file:

```bash
python "AI Powered Virtual Assistant.py"
```

4. Start chatting with Jarvis.

To exit the program, type:

```text
exit
```

## Note

The API key is not included in this repository for security reasons.
